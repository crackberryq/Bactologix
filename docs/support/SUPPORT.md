# Bactologix Support — support and contact

Publisher: **Jimi Goldstein · Human Link**.

For plugin defects, documentation corrections, or reproducible Bactologix software issues, use the [Bactologix GitHub issue tracker](https://github.com/crackberryq/Bactologix/issues). Identify the issue as **Bactologix Support** and include:

- The plugin and application versions, and pipeline commit if relevant.
- What you expected and what happened.
- A minimal reproduction and a short sanitized error excerpt.

The issue tracker is public. Do not post credentials, personal or patient information, raw sequencing data, or confidential logs. An issue submission deliberately shares its contents with the project maintainers and the public; using the plugin alone does not submit an issue.

For privacy questions about the plugin, open an issue containing only the question and any public issue identifier. Do not repost sensitive material. You can edit or delete your own contributions where GitHub permits; GitHub controls its platform's retention and account data settings. Request maintainer assistance if needed, without quoting the sensitive content again.
